# Processo de levantamento de requisitos

## 1ª Etapa

Entrevistas de 15 a 45 minutos.

- Gravar áudio como artefato;
- Transcrição para texto;
- Formulação dos questionários com base no texto transcrito;
- Aplicação dos questionários aos interessados/stakeholder.

## 2ª Etapa

- Com os dados obtidos na etapa 1 geramos o diagrama de contexto;
- Criação dos diagramas de casos de uso;
- Prototipação de telas e uso ---> (Necessita de validação do cliente);
- Prototipação de Funcionalidade;
- Montagem de matriz de rastreabilidade.
