# 🍓 FeedBerry

> Plataforma de feedbacks contínuos entre pessoas e equipes — desenvolvida pelo grupo **Morangotangos**.

O **FeedBerry** é um software de gestão de feedbacks que tem como objetivo tornar a troca de percepções entre colaboradores, líderes e equipes mais simples, frequente e construtiva. O projeto tem como inspiração o software **Aba+**.

## 🎯 Objetivo

Desenvolver, no contexto da disciplina de **Arquitetura de Software**, uma aplicação que permita:

- Enviar e receber feedbacks entre pessoas e equipes;
- Acompanhar o histórico de feedbacks recebidos e enviados;
- Apoiar ciclos de desenvolvimento profissional por meio de feedback contínuo.

> ⚠️ Escopo e requisitos em definição — ver [`docs/`](docs/).
